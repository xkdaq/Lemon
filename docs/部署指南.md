# Lemon 部署指南

一台云服务器 + Docker Compose，部署后端、MySQL、Redis 和 Nginx（同时提供用户端 H5 与管理系统的静态文件）。

```
                ┌──────────────────────────── 服务器（只开放 80 / 443） ───────────────────────────┐
 浏览器 ──https──▶  web (Nginx)                                                                    │
 小程序 ──https──▶   www.域名   → 用户端 H5        + /api/app/**   ─┐                                │
                │   admin.域名 → 管理系统           + /api/admin/** ─┼─▶ server (Spring Boot :8080) ─┐ │
                │   api.域名   → 只开放 /api/app/** （小程序用）   ─┘          │                    │ │
                │   /uploads/** 由 Nginx 直接读共享卷 ◀──────── uploads 卷 ◀─┘                    │ │
                │                                                     mysql (8.4)   redis (7) ◀──┘ │
                └──────────────────────────────────────────────────────────────────────────────────┘
```

- 三个子域名各自只代理自己的接口前缀：用户端域名访问不到管理接口，管理接口只在 admin 域名下可用
- 网页端与接口同域，不需要配置跨域；MySQL / Redis / 后端都不对外暴露端口
- 登录注册接口在 Nginx 层限流（每 IP 每分钟 10 次，突发 10 次），超出返回 429，前端提示“操作太频繁”
- 所有页面带 HSTS、X-Frame-Options（管理端）、nosniff 等安全响应头

## 1. 准备

| 项 | 要求 |
|---|---|
| 服务器 | 国内云服务器 2C4G 起步，Ubuntu 22.04 / 24.04，安全组只放行 80、443（22 限制来源 IP） |
| 域名 | 已完成 ICP 备案；DNS 解析 `www`、`admin`、`api` 和裸域名的 A 记录到服务器 IP |
| 证书 | 三个子域名的 HTTPS 证书（见第 3 节） |
| 软件 | Docker 24+（含 compose 插件）、git |

安装 Docker（Ubuntu）：

```bash
curl -fsSL https://get.docker.com | sh
```

国内服务器拉取 Docker Hub 镜像较慢时，在 `/etc/docker/daemon.json` 配置云厂商提供的镜像加速地址后 `systemctl restart docker`。

## 2. 获取代码与配置

```bash
git clone <仓库地址> /opt/lemon
```

```bash
cd /opt/lemon/deploy && cp .env.example .env
```

编辑 `.env`：

| 变量 | 说明 |
|---|---|
| `DOMAIN` | 主域名，如 `example.com`（会使用 www / admin / api 三个子域名） |
| `MYSQL_ROOT_PASSWORD` / `MYSQL_PASSWORD` / `REDIS_PASSWORD` | 随机强密码，可用 `openssl rand -base64 24` 生成 |
| `ADMIN_INIT_USERNAME` / `ADMIN_INIT_PASSWORD` | 首次启动创建的超级管理员；**生产环境禁止使用默认密码 admin123，否则后端拒绝启动** |
| `NGINX_MODE` | `https` 正式环境；`http` 用于备案 / 证书下来前的内部测试 |

`.env` 包含密码，已被 `deploy/.gitignore` 忽略，不要提交到仓库。

## 3. HTTPS 证书

证书放在 `deploy/certs/`，按域名命名：

```
deploy/certs/www.example.com.pem     deploy/certs/www.example.com.key
deploy/certs/admin.example.com.pem   deploy/certs/admin.example.com.key
deploy/certs/api.example.com.pem     deploy/certs/api.example.com.key
```

两种获取方式任选：

- **云厂商免费证书**（阿里云 / 腾讯云 SSL 证书，单域名、有效期较短需定期续）：为三个子域名各申请一张，下载 Nginx 格式，把 `.pem`/`.crt` 和 `.key` 按上面的名字放好
- **acme.sh 通配符证书**（推荐，自动续期）：用 DNS API 申请 `*.example.com`，再把同一份证书复制成三组文件名；续期后执行 `docker compose restart web`

裸域名 `example.com` 会跳转到 `www`，使用 www 的证书；如果证书不包含裸域名，浏览器访问裸域名会提示证书错误，可以不解析裸域名。

## 4. 首次启动

```bash
cd /opt/lemon/deploy && docker compose up -d --build
```

首次构建需要下载 Maven 和 npm 依赖，约 5～10 分钟。查看状态（都应为 `healthy` / `running`）：

```bash
docker compose ps
```

启动时后端会自动：建表（Flyway）、初始化“政治 / 教育学”模块、创建超级管理员。然后：

1. 打开 `https://admin.example.com`，用 `.env` 里的管理员账号登录，**右上角立即修改密码**
2. 在“管理员”里给录题人员建“录题员”账号
3. 新建题库 → 结构里建科目 / 章节 → 题目管理录题或 Excel 导入
4. 打开 `https://www.example.com` 注册账号、做题验证
5. 跑一遍回归测试（第 8 节）

## 5. 微信小程序

1. 编辑 `lemon-app/.env.mp`，把 `api.example.com` 换成实际的 api 域名
2. `manifest.json` 的 `mp-weixin.appid` 填小程序 AppID
3. 构建：`cd lemon-app && npm ci && npm run build:mp-weixin`
4. 小程序后台 → 开发管理 → 服务器域名：`request 合法域名` 和 `downloadFile 合法域名` 都填 `https://api.example.com`
5. 微信开发者工具导入 `lemon-app/dist/build/mp-weixin`，上传代码后提交审核

> 二期还需要接入微信登录（`/api/app/auth/wx-login`），见 [项目规划](项目规划.md)。

## 6. 备案或证书下来之前：内部测试

`.env` 设置 `NGINX_MODE=http`，可同时把 `HTTP_PORT` 改成其他端口，然后 `docker compose up -d`。在测试电脑的 hosts 文件里把 `www.example.com`、`admin.example.com`、`api.example.com` 指向服务器 IP，用 `http://` 访问。国内服务器在备案前不能对外提供网站服务，仅限内部验证。

## 7. 日常运维

| 操作 | 命令（在 `deploy/` 目录） |
|---|---|
| 查看日志 | `docker compose logs -f --tail=200 server`（或 `web` / `mysql`） |
| 重启某个服务 | `docker compose restart server` |
| 更新版本 | `./backup.sh && git pull && docker compose up -d --build` |
| 进入数据库 | `docker compose exec mysql mysql -uroot -p lemon`（输入 .env 里的 MYSQL_ROOT_PASSWORD） |

- 数据库变更通过 Flyway 迁移脚本自动执行，只能向前；更新前务必先备份
- 回滚：`git checkout <上个版本>` 后 `docker compose up -d --build`；如果新版本已经执行了数据库迁移，需要先用备份恢复数据库（第 9 节）
- 容器日志已限制为每个服务最多 5 × 20MB

## 8. 回归测试

部署或更新后执行（只依赖 Python 3，会自建测试题库并在结束时删除，测试用户会被禁用）：

```bash
python3 scripts/e2e/regression.py --base https://www.example.com --admin-base https://admin.example.com --api-base https://api.example.com --admin-password '<管理员密码>'
```

覆盖：管理员登录、建题库 / 科目 / 章节 / 题目、图片上传与访问、站点隔离、上传目录安全、安全响应头与 HSTS、注册、练习 / 考试 / 错题重练 / 收藏练习、统计、反馈回复、权限。用自签名证书测试时加 `--insecure`。

## 9. 备份与恢复

`deploy/backup.sh` 备份数据库（`mysqldump --single-transaction`，不锁表）和上传的图片到 `deploy/backups/`，默认保留 14 天。加入定时任务（每天 3:30）：

```bash
(crontab -l 2>/dev/null; echo "30 3 * * * cd /opt/lemon/deploy && ./backup.sh >> backups/backup.log 2>&1") | crontab -
```

**备份文件也要定期同步到对象存储或另一台机器**，否则服务器故障时备份会一起丢失。

恢复数据库（会覆盖现有数据）：

```bash
gunzip -c backups/db-20261110-033000.sql.gz | docker compose exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" exec mysql -uroot lemon'
```

恢复图片：

```bash
docker compose exec -T server tar -C /data -xzf - < backups/uploads-20261110-033000.tar.gz
```

## 10. 上线检查清单

- [ ] 管理员已修改初始密码，`.env` 中 `ADMIN_INIT_PASSWORD` 可以改回任意值（只在没有超级管理员时生效）
- [ ] `.env` 里的密码都是随机强密码，文件权限 `chmod 600 .env`
- [ ] 安全组只开放 80 / 443；没有暴露 3306、6379、8080
- [ ] 三个域名 HTTPS 正常，http 自动跳转 https
- [ ] 在 `lemon-app/.env.production` 和 `lemon-admin/.env.production` 填写 `VITE_ICP_NO`（备案号）后重新构建：`docker compose up -d --build web`。用户端首页和管理端登录页底部会显示备案号并链接到 beian.miit.gov.cn；30 日内完成公安备案
- [ ] 定时备份已生效（`backups/backup.log` 有记录），并已同步到异地
- [ ] 回归测试全部通过
- [ ] 小程序合法域名已配置，体验版能正常做题
