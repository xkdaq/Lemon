# 模块激活

题库按**模块**收费：激活某个模块（如政治）后，模块下所有题库都能刷。

## 规则

- **免费 / 收费**：模块可以在后台「模块管理」设为免费（所有人直接刷，不需要激活码）或收费（激活码激活）。「专业二」是免费的。
- **老系统用户**：在「恢复老系统错题」里恢复成功（包括没有可恢复错题的），自动开通「政治」「教育学」到 2027-01-01 当天结束；
  已有更晚的到期时间就不变。上线前已经恢复过的用户由迁移 V14 补开通。
- **新用户注册赠送**：注册成功自动开通「政治」「教育学」N 天，N 是系统参数 `app.register_gift_days`（默认 365，填 0 不赠送）；
  已有更晚的到期时间就不变。2026-11-12 当天已注册的用户由迁移 V16 补开通（注册时间 + 365 天）。
  注册赠送的到期时间晚于 2027-01-01，之后再恢复老系统错题时不会再改这两个模块的到期时间，恢复错题本身不受影响。

- **未激活**：可以浏览所有题库和章节；每个章节免费试做前 N 题（练习 / 背题），N 是系统参数 `app.trial_questions`（默认 5，填 0 不能试做）。
  模拟考试、错题重练、收藏练习、打卡、错题导出都需要激活。
- **激活码**：一个码对应一个模块，只能用一次。有效期两种：
  - 激活后有效 N 天；
  - 到某个固定日期（当天 23:59:59）为止，过了这个日期码也不能再用。
- **顺延**：同一模块没到期再激活，按天数的码从当前到期时间往后加；按日期的码取较晚的那个。
- **到期后**：恢复为未激活（只能试做），之前没做完的整章练习不能继续，重新进入时变成试做。
- 激活码不区分大小写，空格和横线会被忽略；同一用户 1 小时内输错 10 次暂时锁定。

## 后台

- **运营 → 激活码**（超级管理员）：批量生成（最多 1000 个 / 次，可填批次备注，如「闲鱼 11 月」）、按模块 / 状态 / 批次 / 激活码 / 使用者手机号或用户名筛选、
  作废未使用的码、导出 CSV。每个已使用的码能看到使用者、激活时间、激活后模块到期时间。
- **运营 → 模块用户**（超级管理员）：按模块列出开通过的用户，含开通方式（激活码 / 后台开通 / 老系统赠送 / 注册赠送，取最近一次）、
  激活时间、首次开通时间、到期时间、剩余天数、开通次数；每个模块的有效 / 7 天内到期 / 已过期人数。
  可按状态、开通方式、激活日期筛选，关键字搜手机号 / 用户名 / 昵称 / 激活码，可按到期时间、激活时间排序，可导出 CSV；
  「详情」打开该用户的模块权限（全部变更记录、延长、取消）。
- **运营 → 用户管理 → 模块权限**：查看用户各模块到期时间，手动开通 / 延长（加天数或指定到期日）、取消，以及所有变更记录（用了哪个激活码、哪个管理员操作）。
- **运营 → 系统参数**：`app.trial_questions` 试做题数；`app.register_gift_days` 新用户注册赠送天数。

## 数据表

| 表 | 说明 |
|---|---|
| `activation_code` | 激活码；`used_by` / `used_at` / `access_until` 记录谁用了、什么时候、激活后到期时间 |
| `user_module_access` | 用户 × 模块的到期时间（唯一） |
| `module_access_log` | 每次激活 / 后台开通 / 取消 / 老系统赠送 / 注册赠送的记录，含变更前后的到期时间 |
| `module.free` | 1 = 免费模块 |
| `practice_session.trial` | 1 = 试做会话（只有章节前 N 题） |
