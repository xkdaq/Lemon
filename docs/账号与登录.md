# 账号与登录

## 核心规则

- **手机号是唯一身份**：一个手机号只对应一个账号（`app_user.phone` 唯一）。
- **用户名**自动分配（`lemon` + 数字，以字母开头，和手机号区分），**不可修改**；昵称可以随时改。
- 密码、用户名、微信 openid 都只是这个账号的登录方式，不是独立账号。所以 Web 端和小程序端的同一个人天然是同一个账号，
  做题进度、错题、收藏两端互通，**不需要做账号合并**。
- **主推账号密码登录**，短信只在「注册」和「忘记密码」时发，省短信费。
- 小程序**必须授权手机号**才能登录，保证每个账号都有手机号。

相关字段：`username` 用户名；`phone_verified` 手机号是否验证过（短信或小程序手机号快速验证）；
`must_change_password` 后台重置过密码、登录后要提示修改。

## Web 端（已实现）

| 功能 | 接口 | 说明 |
|---|---|---|
| 发验证码 | `POST /api/app/auth/sms-code` `{phone, purpose}` | `purpose = register`：手机号已注册就不发；`reset`：没注册就不发 |
| 注册 | `POST /api/app/auth/register` `{phone, code, password, nickname?}` | 验证码 + 设置密码一步完成，自动分配用户名，注册后自动登录 |
| 登录 | `POST /api/app/auth/login` `{account, password}` | `account` 是手机号或用户名（不区分大小写） |
| 忘记密码 | `POST /api/app/auth/reset-password` `{phone, code, password}` | 重置后自动登录，其他设备全部下线 |
| 修改 / 设置密码 | `POST /api/app/user/password` `{oldPassword?, password}` | 需登录；已有密码要验证原密码，还没密码的（小程序用户）直接设置；其他设备下线 |
| 修改昵称 | `PUT /api/app/user/nickname` `{nickname}` | 需登录 |

后台「用户管理」可以**重置密码**：生成 8 位临时密码（只显示一次，由管理员转告用户），所有设备下线；
用户用临时密码登录后会被要求修改密码。

短信：Spug 推送助手「短信验证码」官方模板，服务器环境变量 `SMS_SPUG_URL` 填完整调用 URL（`https://push.spug.cc/sms/...`），
模板带有效时长时 `SMS_SPUG_MINUTES=5`。开发环境不配置时验证码打印在后端日志里。每次实际发送记录在 `sms_log`，后台「短信记录」可查。

限流：同一手机号 60 秒 1 次、每天 10 次；同一 IP 每小时 20 次；验证码 5 分钟有效、用过即失效、最多试错 5 次。
如果发现被刷短信（短信记录里同一 IP 大量请求、很多从没注册成功的手机号），再加图形验证码 / 滑块。

### 早期"抢注"账号的处理

上线初期「手机号 + 密码」注册时没有验证手机号（这些账号 `phone_verified = 0`），理论上 A 可以用 B 的手机号注册。
真正的机主用「忘记密码」（短信验证手机号）重置密码后，账号就归他：密码被替换，其他设备上的登录全部下线。

## 小程序端（二期，待实现）

登录流程（`POST /api/app/auth/wx-login`，参数 `code` + `phoneCode`）：

1. 前端 `wx.login()` 拿 `code`，后端调 `jscode2session` 换 `openid`（和 `unionid`，如果小程序绑定了开放平台）。
2. 前端用 `<button open-type="getPhoneNumber">` 手机号快速验证拿 `phoneCode`，后端调 `getuserphonenumber` 换手机号。
   这个手机号由微信验证过，等同于短信验证，不额外发短信。
3. 按手机号找账号：
   - **有账号**（包括 Web 注册的）：`phone_verified` 置 1，把 `openid` 绑到这个账号上；
     如果这个账号之前没验证过手机号（可能被抢注），按上面的规则让旧密码失效、其他设备下线；
   - **没有账号**：新建账号，`phone` + `openid` 一起写入，`register_from = 2`，`phone_verified = 1`，
     用 `AppAuthService.insertWithUsername` 分配用户名，没有密码。
4. 登录这个账号，返回 token。

以后再进小程序：先用 `wx.login` 的 openid 找账号，找到就直接登录（静默登录），不用每次授权手机号。

小程序里「设置」可以设置密码（没有密码时不需要原密码，也不发短信），设置后就能在网页上用手机号或用户名 + 密码登录。

### 边界情况

| 情况 | 处理 |
|---|---|
| 账号已经绑了另一个 openid（换了微信号） | 以手机号为准，换成新的 openid（旧微信号不能再静默登录） |
| 这个 openid 已经绑在别的手机号账号上（同一个微信号换了手机号授权） | 提示"该微信已绑定手机号 1xx****xxxx"，不自动改绑，避免一个微信号来回串账号 |
| Web 端用户想用小程序 | 直接在小程序授权同一个手机号，自动进入同一个账号 |
| 小程序用户想用 Web 端 | 先在小程序「设置」里设置密码，再在网页用手机号或用户名 + 密码登录；或者在网页「忘记密码」用短信设置 |
| 用户换了手机号 | 二期再做"更换手机号"（新旧号码都要验证），目前不支持 |

### 准备工作

- 小程序 AppID / AppSecret（服务器环境变量，不进代码仓库），`manifest.json` 里填 AppID。
- 手机号快速验证组件按次收费，需在小程序后台开通并充值。
- 小程序后台把 API 域名配置为 request 合法域名。
